אנו נרגשים להציג את **Atom** - מוח מרכזי אחד המאפשר לחבר את כל הכלים הארגוניים שלכם לגרף ידע אינטראקטיבי, לבצע אוטומציות ותזמונים מורכבים, ולהרחיב את היכולות בעזרת פרוטוקול MCP החדשני עבור סוכני בינה מלאכותית.

## מה זה Atom?

פלטפורמת **Atom** נולדה מתוך צורך הולך וגובר של ארגונים לחבר את מקורות המידע השונים שלהם תחת קורת גג אחת, ולספק גישה מהירה ובטוחה עבור סוכני AI לנתונים ולתהליכים הללו.

המערכת מורכבת מ-3 עמודי תווך מרכזיים:

1. **גרף ידע דינמי (Universal Knowledge Graph):** מיפוי קשרים, ישויות ותהליכים בארגון.
2. **מנוע תזמונים אוניברסלי (Universal Scheduling Engine):** סנכרון ואוטומציה של משימות מורכבות בזמן אמת.
3. **שרתי MCP (Model Context Protocol):** חיבור מאובטח של LLMs לקריאה וכתיבה של המידע.

## מה הצעד הבא?

אם אתם משתמשים חדשים, אנו ממליצים לעבור על [מדריך למשתמשים](/docs/users/getting-started).
אם אתם מפתחים המעוניינים לבנות שרתי MCP מותאמים אישית, היכנסו אל [מדריך למפתחים](/docs/developers/intro).
