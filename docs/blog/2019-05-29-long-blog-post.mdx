פרוטוקול Model Context Protocol (MCP) הוא תקן פתוח המאפשר למפתחים לבנות חיבורים בטוחים ושקופים בין מודלי שפה גדולים (LLMs) לבין מקורות המידע והכלים הארגוניים שלהם. פלטפורמת **Atom** מיישמת את הפרוטוקול הזה בצורה מובנית.

{/* truncate */}

## למה להשתמש ב-MCP?

עד היום, כדי לחבר סוכן AI לנתוני הארגון, היה צורך לכתוב קוד אינטגרציה ייעודי (Ad-hoc API client) עבור כל מודל או סביבת פיתוח. MCP מפשט את התהליך:

- **פרוטוקול אחיד:** חיבור פשוט בין השרת (המידע שלכם) לקליינט (מודל השפה).
- **אבטחה ושליטה:** הגדרת הרשאות קפדנית לכל כלי או פעולה שהסוכן יכול לבצע.
- **תמיכה ב-Python וב-TypeScript:** בנייה מהירה של מחברים בעזרת ספריות ה-SDK הרשמיות.
