# עלינו

**Atom** היא יוזמה לא ארגונית המאפשרת לאטמט משימות ידניות וחזרתיות לכדי אוטומציות פשוטות וחכמות שכל אחד יכול להפעיל.

## עקרונות הליבה שלנו

* **שיתוף פעולה ושיפור מתמיד:** לתמוך ולפתח בעבור כל מי שמוכן לעזור לנו לדייק, לשפר ולייעל את המערכות.
* **להיות תמיד בקידמת הטכנולוגיה:** לחקור ולדחוף את הגבולות של עולמות ה-AI והאוטומציה, בלי לפחד לעשות ניסויים, לבדוק רעיונות חדשים ולטעות.
* **פשטות ופרקטיות:** ליצור כלים ופתרונות שעובדים ועוזרים ביומיום, בלי סיבוכים מיותרים ובמינימום חיכוך.
* **שקיפות וקהילתיות:** לעבוד כקהילת קוד פתוח (Open Source) המשתפת ידע, יוצרת ומפתחת יחד פתרונות ותקנים חופשיים.
