# עלינו

אנחנו קבוצה של מפתחים נלהבים שמאמינים שאוטומציה וגרפי ידע צריכים להיות נגישים לכל ארגון, ללא תלות במורכבות הנתונים שלו. צוות הפיתוח של **Atom** עובד ימים כלילות כדי להבטיח שהמערכת תהיה יציבה, מאובטחת, וקלה להרחבה.

## החזון שלנו

המטרה המרכזית שעמדה לנגד עינינו בתהליך הפיתוח הייתה **לחבר את כל הכלים הארגוניים למוח מרכזי אחד**. 
על ידי שימוש בגרפי ידע אינטראקטיביים ובפרוטוקול המתקדם MCP (Model Context Protocol), פיתחנו פלטפורמה שמאפשרת למודלי בינה מלאכותית לקרוא ולבצע פעולות על המידע שלכם באופן בטוח ושקוף.

## פילוסופיית הפיתוח

1. **אבטחה מעל הכל:** כל פרויקט הוא מבודד (Isolated Tenant). כל הרחבת MCP מאובטחת וניתנת לשליטה.
2. **קוד פתוח (Open Standards):** אנו משתמשים בפרוטוקולים סטנדרטיים ומעודדים את הקהילה לבנות מחברים (Connectors) משלה.
3. **חווית משתמש:** השקענו מאמץ רב בעיצוב ממשק מודרני, חלק ונוח, שמתאים גם למשתמשים טכניים וגם לכאלה שפחות.
