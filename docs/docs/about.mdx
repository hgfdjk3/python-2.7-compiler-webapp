# עלינו

אנחנו קבוצה של מפתחים נלהבים שמאמינים שאוטומציה צריכה להיות פשוטה. המטרה שלנו היא לאפשר לכל מפתח, חוקר מודיעין, ולכלל מערך העובדים, לאטמט פעולות ידניות וחזרתיות לכדי אוטומציות פשוטות. צוות הפיתוח של **Atom** עובד ימים כלילות כדי להבטיח שהמערכת תהיה יציבה, מאובטחת, וקלה להרחבה.

## החזון שלנו

אנחנו בונים תשתיות, Harnesses, וכלים כדי שכל מה שחושף אותך ירוץ חלק יותר. המטרה המרכזית שעמדה לנגד עינינו בתהליך הפיתוח הייתה **לחבר את כל הכלים הארגוניים ולהנגיש אותם בצורה קלה ונוחה**.
על ידי שימוש בגרפי ידע אינטראקטיביים ובפרוטוקול המתקדם MCP (Model Context Protocol), פיתחנו פלטפורמה שמאפשרת למפתחים להנגיש לכם את המערכות והכלים שלהם בסביבה בטוחה ושקופה.

## פילוסופיית הפיתוח

1. **אבטחה מעל הכל:** כל פרויקט הוא מבודד (Isolated Tenant). כל הרחבת MCP מאובטחת וניתנת לשליטה.
2. **קוד פתוח (Open Standards):** אנו משתמשים בפרוטוקולים סטנדרטיים ומעודדים את הקהילה לבנות מחברים (Connectors) משלה.
3. **חווית משתמש:** השקענו מאמץ רב בעיצוב ממשק מודרני, חלק ונוח, שמתאים גם למשתמשים טכניים וגם לכאלה שפחות.
