# מבוא לפיתוח חיבורי MCP

**חלק זה מתמקד אך ורק בבניית חיבורי Model Context Protocol (MCP)**.
כאן תמצאו את כל התשתיות, ה-Harnesses והכלים הדרושים כדי להנגיש את המערכות שלכם למשתמשי הקצה בקלות ובנוחות מרבית.

:::info[מה זה MCP?]

Model Context Protocol הוא פרוטוקול פתוח וסטנדרטי (מבית Anthropic) שמאפשר ליישומים לחשוף כלים (Tools) ונתונים מותאמים אישית החוצה. 
כאשר אתם מחברים שרת MCP ל-Atom, אתם מאפשרים למערכת (ולמנועי ה-AI שלה) להפעיל את הקוד שלכם בבטחה ולקרוא מידע ממסדי הנתונים הפנימיים שלכם.

:::

## למה לבנות שרת MCP ל-Atom?

אם אי פעם רציתם שפעולות ב-Atom יצליחו לתשאל את ה-Jira הארגוני שלכם, לעדכן שורות במסד הנתונים הסודי שלכם, או להפעיל סקריפטים מורכבים בשרתים הפנימיים שלכם - הדרך הנכונה לעשות זאת היא לא לפתוח חורי אבטחה ב-Firewall, אלא להרים שרת MCP קטן ברשת הפנימית ולחבר אותו ל-Atom!

## פרוטוקולי תקשורת

מכיוון שמשתמשי המערכת מתחברים לשרתי MCP חיצוניים (שאינם רצים על אותו שרת של המערכת עצמה), פרוטוקול התקשורת בו אנו משתמשים חייב להיות **Streamable HTTP (SSE - Server-Sent Events)**. שיטה זו מאפשרת תקשורת רציפה, יציבה ובטוחה בין Atom לבין שרת ה-MCP שלכם.

בפרקים הבאים נלמד כיצד לבנות שרת MCP צעד אחר צעד, ואיך לחבר אותו למערכת.
