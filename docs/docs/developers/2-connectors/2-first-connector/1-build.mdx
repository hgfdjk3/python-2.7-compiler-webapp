# בניית השרת

במדריך זה נלמד כיצד ליצור חיבור MCP פשוט שמספק כלים (Tools) לפלטפורמה. בעזרת חיבור זה תוכלו לחשוף פונקציות קוד לשימוש על ידי סוכני ה-AI של המערכת.

## יצירת שרת MCP בפייתון

במערכת Atom אנו ממליצים להשתמש בספריית `fastmcp` שמפשטת את תהליך יצירת הכלים. 

ראשית, התקינו את הספרייה:

```bash title="Terminal"
pip install fastmcp
```

ניצור קובץ פייתון חדש בשם `server.py` ונוסיף אליו את הקוד הבא:

```python title="server.py"
from fastmcp import FastMCP

# אתחול שרת ה-MCP עם שם לזיהוי
mcp = FastMCP("My First Connector")

@mcp.tool()
def get_greeting(name: str) -> str:
    """מחזיר ברכת שלום אישית."""
    return f"Hello, {name}!"

if __name__ == "__main__":
    # הרצת השרת. כברירת מחדל אנו מריצים אותו על גבי HTTP ו-SSE
    mcp.run(transport="streamable-http", host="127.0.0.1", port=8015, path="/sse")
```

### מה קורה פה?
1. אנו מייבאים את `FastMCP` ומאתחלים שרת.
2. תגית ה-`@mcp.tool()` מסמנת למערכת שהפונקציה תהיה חשופה ככלי שאפשר להפעיל.
3. אנו מגדירים Type Hints (`name: str`) ו-Docstring (`"""מחזיר ברכת שלום אישית."""`). אלו הם נתונים קריטיים, משום שהמערכת משתמשת בהם כדי לדעת איזה מידע להעביר לפונקציה ואיך היא יכולה להשתמש בה.
4. בסוף, אנחנו מריצים את השרת כדי שימתין לקריאות (בפורט 8015).

:::tip[פריסת השרת בייצור (Production)]
מומלץ מאוד לפרוס את שרתי ה-MCP שלכם על גבי סביבת **OpenShift** הארגונית. פריסה כזו מבטיחה זמינות גבוהה, ניהול קל של משאבים, וחיבור מאובטח ויציב למערכת Atom.
:::

כעת, כששרת ה-MCP רץ, נוכל לחבר אותו למערכת! המשיכו לעמוד הבא כדי לראות איך.
