# חיבור למערכת (Atom)

לאחר שיצרנו והרצנו את שרת ה-MCP שלנו, הגיע הזמן לחבר אותו למערכת Atom. כך נעשה זאת שלב אחר שלב:

## הוספת החיבור למערכת

1. **היכנסו לממשק הניהול:** פתחו את פרויקט Atom שלכם בדפדפן.
2. **עברו למסך החיבורים:** בתפריט הראשי (או בהגדרות הפרויקט), חפשו את המסך "ניהול חיבורים" או "Connectors / Integrations".
3. **הוספת חיבור חדש:** לחצו על "Add Connector" או "הוסף חיבור".
4. **בחירת סוג התקשורת:** מכיוון שבמדריך הקודם הרצנו את השרת על גבי MCP streamable HTTP, בחרו באפשרות **HTTP** (או **MCP streamable HTTP**).
5. **הזנת כתובת השרת (URL):**
   - הזינו את הכתובת שעליה השרת מאזין. 
   - בדוגמה שלנו השתמשנו בכתובת `http://127.0.0.1:8000` (או הכתובת הרלוונטית אם הפעלתם משרת מרוחק).
6. **שמירה:** לחצו על שמור או Connect.

## בדיקת החיבור

ברגע שהחיבור יתווסף בהצלחה:
- המערכת תשדר קריאה ראשונית לשרת כדי לקבל את רשימת הכלים (Tools) הזמינים.
- תוכלו לראות בממשק Atom שהכלי שיצרנו (`get_greeting`) מזוהה על ידי המערכת.

### שימוש בצ'אט

כעת, כל שעליכם לעשות הוא לפתוח את הצ'אט של הסוכן (Agent) ולבקש ממנו בקשה חופשית, למשל:

> *"תגיד שלום לישראל ישראלי בעזרת הכלי החדש שחיברנו."*

הסוכן יזהה באופן אוטומטי שהכלי `get_greeting` מתאים לבקשה שלכם, יפעיל אותו מאחורי הקלעים ויציג לכם את התשובה שהוא קיבל!
