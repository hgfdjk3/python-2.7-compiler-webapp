# תיעוד למפתחים

ברוכים הבאים לתיעוד המפתחים של Atom. חלק זה מיועד למפתחים המעוניינים להרחיב ולהטמיע את המערכת.

כחלק מזה, אנו מספקים לכם את כל התשתיות, ה-Harnesses והכלים הדרושים כדי להנגיש את המערכות שלכם למשתמשי הקצה בקלות ובנוחות מרבית, וכן להטמיע את הכלים שלנו במערכות שלכם.

תיעוד המפתחים מחולק לשתי קטגוריות מרכזיות:

1. **הטמעה (Embedding):** כיצד להטמיע את ממשק ה-Chat של Atom במערכות חיצוניות אחרות.
2. **בניית Connectors (MCP):** כיצד לבנות חיבורי Model Context Protocol (MCP) כדי לחשוף כלים ומידע מותאם אישית.

בחרו באחת הקטגוריות כדי להתחיל.
