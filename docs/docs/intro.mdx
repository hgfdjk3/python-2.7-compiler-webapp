# ברוכים הבאים לתיעוד של Atom

## מה זה אטום (Atom)?
הדרך הקלה ביותר לאטמט את המשימות החזרתיות והידניות בעבודה. אטום מאפשרת לכם לקחת פעולות שאתם עושים שוב ושוב, ולהפוך אותן לאוטומציות פשוטות שכל אחד יכול לבנות ולהפעיל.

## איך זה עובד?
אנחנו עוזרים למפתחים להנגיש לכם את המערכות והכלים שלהם בצורה סופר נוחה. במקום להסתבך, אנחנו דואגים לכל התשתיות מאחורי הקלעים כדי שהעבודה שלכם תזרום חלק, מהר ובלי מאמץ.

:::tip[ניווט מהיר]

השתמשו בכרטיסיות מטה כדי לקפוץ ישירות לקטגוריה הרלוונטית עבורכם. רכיב ה-`DocCardList` חושף בצורה חכמה את כל התיקיות בסביבה!

:::
