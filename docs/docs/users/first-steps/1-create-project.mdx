# יצירת פרוייקט

התחלת העבודה עם Atom היא פשוטה ומהירה. עקבו אחר הצעדים הבאים כדי להקים את הפרוייקט הראשון שלכם בממשק המשתמש.

## יצירת פרוייקט ראשון

כדי להתחיל לעבוד ולבנות את המערכת שלכם, יש ליצור תחילה פרוייקט ייעודי שישמש כסביבת עבודה נפרדת.

1. לחצו על כפתור **"פרויקט חדש"** (New Project) המופיע בסרגל העליון או במרכז לוח הבקרה.
2. תנו שם ברור ומזהה לפרויקט שלכם (לדוגמה: "סנכרון לידים מ-Salesforce").
3. תנו תיאור קצר כדי לעזור לחברי הצוות שלכם להבין את מטרת הפרויקט.
4. לחצו על **שמור** (Save).
