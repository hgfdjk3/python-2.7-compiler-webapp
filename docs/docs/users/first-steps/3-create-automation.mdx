# יצירת אוטומציה

מנוע האוטומציה של **Atom** מאפשר לכם להריץ משימות ברקע באופן אוטומטי מלא, ללא צורך בכתיבת קוד (No-Code). כל מה שצריך לעשות הוא להגדיר מהו הטריגר שיפעיל את התהליך, ואיזו פעולה תבוצע בתגובה.

![עורך האוטומציות הגרפי במערכת](/img/automation_builder.png)

## סוגי טריגרים (Triggers)

כדי שאוטומציה תתחיל לרוץ, עליה לקבל אירוע מפעיל. במערכת קיימים שני סוגי טריגרים עיקריים:

1. **מבוססי זמן (Time-Based / Cron):** להריץ משימות בשעה מסוימת או במרווחים קבועים (לדוגמה: בכל יום בשעה 8:00 בבוקר).
2. **מבוססי אירוע (Event-Based):** האוטומציה תופעל בתגובה לשינוי כלשהו בתוך המערכת (לדוגמה: כאשר נוסף מידע חדש לגרף הידע).

## איך ליצור אוטומציה חדשה?

כדי להגדיר אוטומציה ראשונה בממשק המשתמש:

1. נווטו ללשונית **Schedules** (תזמונים) או **Automations** בתפריט הראשי.
2. לחצו על כפתור **צור תזמון חדש** (Create New Schedule / Automation).
3. **שם האוטומציה:** הזינו שם ברור המתאר את הפעולה (למשל: "גיבוי יומי של נתוני לקוחות ל-Slack").
4. **בחירת טריגר:** בחרו בין מבוסס זמן למבוסס אירוע והגדירו את התנאי הרצוי.
5. **בחירת פעולה (Action / Tool):** בחרו מתוך רשימת הכלים הזמינים במערכת. הכלים שיופיעו תלויים בחיבורים (Connectors) שהפעלתם בשלב הקודם.
6. לחצו על **שמור** (Save) כדי להפעיל את האוטומציה.

:::info[זמינות פעולות]

אם פעולה מסוימת שאתם מחפשים אינה מופיעה ברשימה, ודאו שהמחבר (Connector) המתאים מופעל ונמצא במצב פעיל בספריית המחברים.

:::
