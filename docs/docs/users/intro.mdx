# מבוא למשתמש

ברוכים הבאים למערכת **Atom** – פלטפורמת התזמון וגרף הידע האוניברסלית.
מערכת זו מאפשרת לכם לנהל תהליכים מורכבים, ליצור תזמונים ואוטומציות, ולנהל קשרים בצורה נוחה באמצעות ממשק גרפי אינטראקטיבי מתקדם.

:::info[מהי מערכת Atom?]

Atom נועדה להיות הלב הפועם של האוטומציה והידע בארגון שלכם. היא משלבת מנוע תזמונים ואוטומציות עוצמתי עם מסד נתונים גרפי גמיש, כך שתוכלו לא רק לתזמן משימות, אלא גם להבין ויזואלית כיצד הנתונים והתהליכים שלכם קשורים זה לזה.

:::

## מה המערכת מציעה?

1. **ניהול פרויקטים וסביבות עבודה**: סביבות עבודה מבודדות. השתמשו בפרויקטים כדי להפריד בין תהליכים שונים בארגון שלכם (לדוגמה: פרויקט לצוות פיתוח, ופרויקט לצוות שיווק).
2. **חיבורים וסנכרון (Connectors)**: הפעלת חיבורים למקורות מידע חיצוניים (Slack, Salesforce, GitHub ועוד) ישירות מתוך ספריית החיבורים בממשק.
3. **אוטומציות ותזמונים**: הגדרת משימות מתוזמנות (לפי זמן או ביטויי Cron) או מבוססות אירועים, ועריכתן דרך בונה האוטומציות הגרפי.
4. **גרף ידע**: צפייה, יצירה וניהול של ישויות וקשרים (Nodes & Edges) בצורה ויזואלית וידידותית למשתמש.

:::tip[טיפ למתחילים]

מומלץ להתחיל ב[מדריך למשתמש המתחיל](./getting-started.mdx) כדי להקים את הפרויקט הראשון שלכם וללמוד את יסודות הניווט במערכת.

:::

## שלבי העבודה והתיעוד

התיעוד למשתמשים מחולק לשלבים הבאים לפי סדר העבודה המומלץ:

1. **[שלב 1: מדריך למשתמש המתחיל](./getting-started.mdx)** - יצירת פרויקט ראשון והתמצאות בממשק הניהול.
2. **[שלב 2: חיבור Connectors](./connectors.mdx)** - כיצד להפעיל ולחבר כלים ומקורות מידע חיצוניים למערכת שלכם.
3. **[שלב 3: יצירת אוטומציות](./automations/scheduling.mdx)** - הגדרת משימות, תזמונים, עריכת אוטומציות וניטור הריצות.
4. **[שלב 4: יצירת Knowledge graph](./knowledge-graph.mdx)** - בנייה וניהול של רשת ישויות וקשרים להבנת התהליכים בארגון.
