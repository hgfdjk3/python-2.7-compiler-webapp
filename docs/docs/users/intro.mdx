# מבוא למשתמש

ברוכים הבאים למערכת **Atom** – הדרך הקלה ביותר לאטמט את המשימות החזרתיות והידניות בעבודה.
המערכת מאפשרת לכם לקחת פעולות ידניות שאתם עושים שוב ושוב, ולסגור אותן באוטומציות פשוטות שכל אחד יכול לבנות ולהפעיל, הכל דרך ממשק גרפי מתקדם.

:::info[איך זה עובד?]

אנו עוזרים למפתחים בארגון להנגיש עבורכם את כל המערכות והכלים בצורה סופר נוחה. במקום להסתבך עם קוד או הגדרות טכניות, אנחנו דואגים לכל התשתיות מאחורי הקלעים כדי שהעבודה שלכם תזרום חלק, מהר ובלי מאמץ. 

:::

## לאילו פעולות המערכת מתאימה?

המערכת בנויה לייעל ולהתמודד עם סוגי הפעולות הבאים:

- **פעולות ידניות וחזרתיות (רפטטיביות):** משימות שגרתיות שדורשות לבצע את אותן הפעולות שוב ושוב באותה צורה, ללא צורך בחשיבה מורכבת.
- **חיבוריות וסנכרון בין מערכות שונות:** העברת נתונים מפלטפורמה אחת לאחרת, אינטגרציה, ותקשורת רציפה בין הכלים השונים בארגון שלכם.
- **הבנת תוכן והקשרים בעזרת בינה מלאכותית (AI):** בניגוד למערכות לעיבוד נתונים קלאסיות (כמו מערכת Flow שנועדה למטרות אחרות של קליטת כמויות מידע), אטום משתמשת ב-AI כדי *להבין* באמת את התוכן, לנתח אותו ולזהות הקשרים וחיבורים מורכבים. זהו כלי אידיאלי למחקרי מודיעין, בהם לא מספיק רק לאסוף נתונים אלא נדרשת יכולת ניתוח סמנטית של הטקסט והמידע.

## למה המערכת פחות מתאימה?

- **פעולות הדורשות שיקול דעת אנושי מורכב:** אטום מצוינת בביצוע תהליכים עם חוקיות ברורה, אך אינה מיועדת להחליף אינטואיציה אנושית, יצירתיות, או קבלת החלטות עדינות שאינן ניתנות לקידוד.
- **מערכות זמן-אמת קריטיות (Real-Time):** המערכת נועדה לאוטומציה ותזמונים אסינכרוניים, והיא פחות מתאימה למערכות ליבה הדורשות זמני תגובה אפסיים (Low Latency) בסדרי גודל של אלפיות שנייה.
