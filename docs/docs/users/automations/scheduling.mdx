# תזמון אוטומציות

מנוע האוטומציה של **Atom** מאפשר לכם להריץ משימות ברקע באופן אוטומטי מלא, ללא צורך בכתיבת קוד (No-Code). כל מה שצריך לעשות הוא להגדיר מהו הטריגר שיפעיל את התהליך, ואיזו פעולה תבוצע בתגובה.

![עורך האוטומציות הגרפי במערכת](/img/automation_builder.png)

## סוגי טריגרים (Triggers)

כדי שאוטומציה תתחיל לרוץ, עליה לקבל אירוע מפעיל. במערכת קיימים שני סוגי טריגרים עיקריים:

1. **מבוססי זמן (Time-Based / Cron):**
   - מאפשר להריץ משימות בשעה מסוימת או במרווחים קבועים (לדוגמה: בכל יום בשעה 8:00 בבוקר, או בכל שעה עגולה).
   - המערכת משתמשת בתחביר קרון (Cron Syntax) סטנדרטי (כמו `0 8 * * *`). 
   - בממשק המשתמש תמצאו **מחולל קרון מובנה** שמסייע לכם להגדיר את זמני ההרצה בקלות ללא צורך בהכרת התחביר.

2. **מבוססי אירוע (Event-Based):**
   - האוטומציה תופעל בתגובה לשינוי כלשהו בתוך המערכת.
   - לדוגמה: כאשר נוסף צומת (Node) חדש מסוג `Lead` לגרף הידע, או כאשר עודכן סטטוס של משימה קיימת.

---

## איך ליצור תזמון חדש?

כדי להגדיר תזמון אוטומטי ראשון בממשק המשתמש:

1. נווטו ללשונית **Schedules** (תזמונים) בתפריט הראשי.
2. לחצו על כפתור **צור תזמון חדש** (Create New Schedule).
3. **שם האוטומציה:** הזינו שם ברור המתאר את הפעולה (למשל: "גיבוי יומי של נתוני לקוחות ל-Slack").
4. **בחירת טריגר:** בשדה הטריגר, בחרו בין **Time-Based** לבין **Event-Based**.
5. **הגדרת התנאי:**
   - עבור מבוסס זמן: הזינו את ביטוי ה-Cron או השתמשו בממשק הגרפי לבחירת זמנים.
   - עבור מבוסס אירוע: בחרו את סוג הישות בגרף הידע ואת סוג השינוי (יצירה/עדכון/מחיקה) שמפעילים את האוטומציה.
6. **בחירת פעולה (Action / Tool):**
   - בחרו מתוך רשימת הכלים הזמינים במערכת. הכלים שיופיעו לכם תלויים ב-**Connectors שהפעלתם בשלב הקודם** (לדוגמה: שליחת הודעה דרך Slack Connector).
7. לחצו על **שמור** (Save) כדי להפעיל את האוטומציה.

:::info[זמינות פעולות]

אם פעולה מסוימת שאתם מחפשים אינה מופיעה ברשימה, ודאו שהמחבר (Connector) המתאים מופעל ונמצא במצב פעיל בספריית המחברים.

:::
