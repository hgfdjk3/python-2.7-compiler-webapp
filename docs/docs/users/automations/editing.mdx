# עריכה וניהול אוטומציות

לאחר שיצרתם אוטומציות במערכת, תוכלו לנהל אותן, לשנות את הגדרותיהן, להפסיקן זמנית או למחוק אותן לחלוטין מתוך לוח הבקרה.

## צפייה באוטומציות קיימות

במעבר ללשונית **Schedules** (תזמונים), תראו רשימה מפורטת של כל האוטומציות שהוגדרו בפרויקט שלכם. לכל אוטומציה מופיע כרטיס ניהול המציג:
- שם האוטומציה ותיאורה.
- סוג הטריגר וזמן הריצה הבא (למשל: "ירוץ בעוד שעתיים" או "ממתין לאירוע").
- סטטוס הפעילות (פעיל / מושבת).

---

## שינוי מצב פעילות (פעיל / כבוי)

אין צורך למחוק אוטומציה אם ברצונכם להפסיק אותה לזמן מה. תוכלו להשתמש במתג ההפעלה המהירה:

1. אתרו את האוטומציה הרלוונטית ברשימה.
2. העבירו את מתג הסטטוס (Toggle Switch) למצב כבוי כדי להשבית את הריצות.
3. כדי להחזיר אותה לפעילות, העבירו את המתג חזרה למצב פעיל.

---

## עריכת הגדרות האוטומציה

אם ברצונכם לשנות את זמני ההרצה, לעדכן את שם האוטומציה, או לשנות את הפרמטרים של הפעולה:

1. לחצו על כפתור **עריכה** (Edit / אייקון העיפרון) בכרטיס האוטומציה הרלוונטי.
2. ייפתח חלון עריכה זהה לחלון היצירה.
3. בצעו את השינויים הנדרשים:
   - תוכלו לשנות את ביטוי ה-Cron או את סוג האירוע המפעיל.
   - תוכלו לעדכן את נתוני הקלט שנשלחים לפעולות החיצוניות (למשל, לשנות את ערוץ ה-Slack אליו נשלח הדיווח).
4. לחצו על **שמור שינויים** (Save Changes).

---

## מחיקת אוטומציה

:::warning[מחיקה לצמיתות]

מחיקת אוטומציה היא פעולה סופית שלא ניתן לבטל. היסטוריית הריצות הקודמות של האוטומציה הזו עשויה להימחק גם היא.

:::

אם אינכם זקוקים יותר לאוטומציה מסוימת:
1. לחצו על כפתור **מחיקה** (Delete / אייקון פח האשפה) בכרטיס האוטומציה.
2. אשרו את תיבת הדו-שיח ששואלת אתכם האם אתם בטוחים בביצוע המחיקה.
