# ניטור והיסטוריית ריצות

לאחר שהגדרתם והפעלתם את האוטומציות שלכם, המערכת מתחילה להריץ אותן ברקע. ממשק הניהול של **Atom** מציע כלים מתקדמים לניטור בזמן אמת, איתור תקלות וקריאת יומני הרצה (Logs).

## היסטוריית ריצות (Run History)

עבור כל אוטומציה שהוגדרה, תוכלו לראות בממשק המשתמש את היסטוריית הריצות המלאה שלה. כדי לגשת אליה:
1. עברו ללשונית **Schedules** (תזמונים).
2. לחצו על כפתור **History** (היסטוריה / אייקון של שעון) בכרטיס האוטומציה.
3. ייפתח מסך המציג את רשימת כל ההפעלות האחרונות של אותה אוטומציה.

כל שורת ריצה מציגה:
- **זמן התחלה וסיום:** מועד ההרצה המדויק ומשך זמן הביצוע.
- **סטטוס ריצה:**
  - 🟢 **ירוק (Success):** האוטומציה וכל הפעולות שלה הסתיימו בהצלחה ללא שגיאות.
  - 🔴 **אדום (Failed):** התרחשה שגיאה במהלך הביצוע (לדוגמה: שגיאת חיבור לשירות החיצוני או קלט לא תקין).

---

## קריאת יומני הרצה (Logs)

במידה וההרצה נכשלה, או שאתם מעוניינים לבדוק את התפוקה והמידע שנאסף במהלכה:

1. לחצו על שורת הריצה הרלוונטית מתוך רשימת ההיסטוריה.
2. המערכת תפתח חלון צדי או תיבת שיח המציגה את **יומן הריצה המלא (Logs)**.
3. היומן מציג צעד-אחר-צעד את מה שקרה:
   - קבלת הטריגר.
   - שליחת המידע למחבר (Connector).
   - תגובת השירות החיצוני.
   - שגיאות מפורטות במידה והיו (לדוגמה: `401 Unauthorized` במקרה של מפתח API פג תוקף).

:::tip[איתור תקלות מהיר]

מרבית תקלות הריצה נובעות משינויים בהרשאות בשירותים החיצוניים שלכם. במקרה של כישלון, מומלץ לבדוק את יומן הריצה, לאתר את הודעת השגיאה, ואז לעבור לעמוד ה-Connectors כדי לוודא שמפתחות הגישה שלכם עדיין בתוקף.

:::

## ניטור כללי בדאשבורד (Dashboard Overview)

אם ברצונכם לקבל תמונה כוללת של בריאות המערכת ללא כניסה לכל משימה בנפרד:

- חזרו למסך הבית הראשי של המערכת.
- הביטו בגרף **סטטוס משימות (Task Status)** המציג תצוגה גרפית של כל הריצות ב-24 השעות האחרונות.
- הגרף מאפשר לכם לזהות בקלות עליות חריגות בכמות הכישלונות, ומספק אינדיקציה מהירה לכך שייתכן וישנה בעיית תקשורת כללית באחד מהחיבורים שלכם.
