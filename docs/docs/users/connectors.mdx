# חיבור Connectors

מחברים (Connectors) הם הגשרים המאפשרים למערכת **Atom** להתחבר לשירותים וכלים חיצוניים (כמו Slack, Salesforce, GitHub ועוד). דרך ממשק המשתמש תוכלו להפעיל מחברים קיימים, להגדיר להם מפתחות גישה, ואף לחבר מחברים מותאמים אישית.

![ספריית ה-Connectors במערכת](/img/connectors_library.png)

## ספריית ה-Connectors (Connectors Library)

כדי לגלות ולנהל את המחברים הזמינים במערכת, עברו ללשונית **Connectors** (או "ספריית מחברים") בסרגל הצידי:

1. **חיפוש וסינון:** השתמשו בתיבת החיפוש או בסינון לפי קטגוריות (כמו Database, CRM, Communication) כדי למצוא את המחבר הרצוי.
2. **הפעלה וכיבוי (Enable/Disable):** לכל מחבר מופיע כרטיס המציג את תיאורו. לחיצה על כפתור ההפעלה/כיבוי (Toggle) תפעיל או תשבית את המחבר עבור סביבת העבודה שלכם.
3. **הגדרות חיבור:** חלק מהמחברים דורשים הגדרות מוקדמות (למשל, מפתח API או כתובת שרת). בעת הפעלת המחבר (או בלחיצה על כרטיס המחבר), ייפתח חלון הגדרות בו עליכם להזין את הערכים הנדרשים.

:::info[הגדרות מאובטחות]

כל השדות הרגישים שאתם מזינים (כמו סיסמאות ומפתחות API) מוצפנים ונשמרים בצורה מאובטחת. הם ישמשו אך ורק את האוטומציות והתהליכים שתגדירו בתוך הפרויקט שלכם.

:::

## חיבורים מותאמים אישית (Custom Connections)

במידה והארגון שלכם פיתח מחבר ייעודי שאינו מופיע בספרייה הסטנדרטית, תוכלו לחבר אותו ישירות דרך ממשק המפתחים (Developers):

1. נווטו לעמוד **Developer Connections** (תחת אזור המפתחים במערכת).
2. לחצו על כפתור **Add Connection** (הוסף חיבור).
3. מלאו את פרטי החיבור בחלון שייפתח:
   - **שם החיבור (Connection Name):** שם מזהה (לדוגמה: "מערכת לקוחות פנימית").
   - **צבע מותג ואייקון:** בחרו אייקון וצבע שייצגו את המחבר שלכם בלוחות הבקרה של האוטומציה.
   - **תיאור ותגיות:** תיאור קצר ותגיות שיעזרו למשתמשים אחרים להבין מה המחבר עושה.
   - **כתובת קצה (HTTP Endpoint URL):** כתובת השרת שמריץ את שירות ה-MCP (לדוגמה: `http://localhost:8000/`).
   - **הגדרת שדות כותרת (Headers Schema):** הגדירו את שמות השדות שמשתמשי המערכת יצטרכו להזין בעת חיבור השרת (לדוגמה: `Authorization` או `X-API-Key`).
4. לחצו על **Connect Server** (חבר שרת).

לאחר חיבור מוצלח, כל הכלים והיכולות של המחבר החדש יהיו זמינים באופן מיידי לשימוש בגרף הידע ובמנוע האוטומציות שלכם!
