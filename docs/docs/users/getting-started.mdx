# מדריך למשתמש המתחיל

התחלת העבודה עם Atom היא פשוטה ומהירה. עקבו אחר הצעדים הבאים כדי להקים את הפרויקט הראשון שלכם בממשק המשתמש.

## יצירת חשבון או התחברות

:::warning[תשומת לב]

אם הארגון שלכם משתמש בחיבור מרוכז (SSO כגון Google או Okta), הקפידו להתחבר דרך כפתור ה-SSO הייעודי במסך ההתחברות כדי להימנע מיצירת חשבון כפול.

:::

1. היכנסו לעמוד ההתחברות של המערכת בדפדפן.
2. לחצו על **הרשמה** (Sign Up) והזינו את פרטיכם או התחברו ישירות דרך כפתור ה-SSO.
3. אשרו את כתובת הדוא"ל שלכם באמצעות הקישור שנשלח אליכם (במידה ונרשמתם עם דוא"ל וסיסמה).

## סקירת לוח הבקרה (Dashboard)

לאחר ההתחברות, תועברו ישירות למסך הבית הראשי של המערכת. 

:::info[ניווט קל]

בצד ימין (או שמאל, בהתאם לשפת הממשק של הדפדפן שלכם) תמצאו את סרגל הניווט הראשי, דרכו תוכלו לעבור בין הפרויקטים השונים, ספריית ה-Connectors, האוטומציות וגרף הידע.

:::

לוח הבקרה מציג עבורכם מידע קריטי במבט על:
- **פרויקטים פעילים:** רשימה מהירה וגישה קלה לכל הפרויקטים הפעילים תחת ניהולכם.
- **סטטוס משימות ואוטומציות:** גרף פעילות אינטראקטיבי המראה את כמות הריצות שבוצעו בהצלחה וכמות הריצות שנכשלו ב-24 השעות האחרונות.

## יצירת פרויקט ראשון

כדי להתחיל לעבוד ולבנות את המערכת שלכם, יש ליצור תחילה פרויקט ייעודי שישמש כסביבת עבודה נפרדת.

1. לחצו על כפתור **"פרויקט חדש"** (New Project) המופיע בסרגל העליון או במרכז לוח הבקרה.
2. תנו שם ברור ומזהה לפרויקט שלכם (לדוגמה: "סנכרון לידים מ-Salesforce").
3. תנו תיאור קצר כדי לעזור לחברי הצוות שלכם להבין את מטרת הפרויקט.
4. לחצו על **שמור** (Save).
